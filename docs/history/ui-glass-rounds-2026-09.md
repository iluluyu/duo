## DESIGN.md §3.11 存档块（六修 / 四修五修 / 三修）

- **六修：悬浮玻璃岛替代霜层带（2026-09-21 晚，用户否决五修："诡异、
  纯黑屏障、不通透"，Gemini 两轮鉴定后结案）**：
  - **架构反转**：不再画「滚动时浮现的霜层带」（出现/消失=诡异感
    来源，暗色厚染=黑墙），改为**内容全出血上卷 + 控件坐玻璃岛**——
    Apple scrollEdge 语义（材质常驻，静止时岛下是空画布=隐约，内容
    滚入=透出模糊色块），ColorOS 浮岛形态。
  - **两块岛**：分段胶囊岛（~224×44 r22，slot0）+ 搜索岛（搜索框
    外扩 10/6，slot1）；glass.rs `VeilMask::Rounded`（SDF 圆角满域
    蒙版，σ12）；配方=模糊贴图 α150 + 透染（暗 58,58,60@72 / 亮
    白@78）+ 1px 亮边（暗@22 / 亮@90）——总有效不透明度 ~0.70，
    **通透**而非屏障。
  - **全出血**：设置视口 vp.top 64→0（玻璃开时；内容 y 不变）；首
    页网格 clip.top 抬到搜索岛顶（磁贴从搜索岛下滚过），网格先画、
    搜索岛后画盖其上。
  - **新鲜度**：`pump_veil_refresh` 滚动中每 120ms 重捕快照 + 停稳
    450ms 终帧；重捕前 2 帧抑制岛贴图（`veil_suppress`，只画透染）
    防「模糊自己」反馈环——岛内模糊跟随滚动内容（Gemini 一轮核心
    批评：陈旧快照=平板贴纸）。
  - **透染链**：搜索胶囊填充玻璃档 α210/225、分段轨道 α185/205
    （实心填充会盖死玻璃感）。
  - 网格底缘仅 12px α55 小气垫（bg 色）；玻璃关=回 64px 硬让位 +
    实心填充（原始朴素回退）。
  - 评审：Gemini 3.1-Pro 一轮（指出陈旧快照/实心搜索）→ 修复 →
    二轮裁决「达成通透悬浮玻璃岛，结案」（Opus 运行时当晚不可用）。
- **虚化四修/五修（2026-09-21，Gemini 设计辅助 + Opus 品味鉴定双
  评审三轮闭环，终审「自然景深」达标）**：
  - σ 6→**18**（双评审共识：小 σ 内容结构可辨=污渍感，大 σ 打碎
    成色晕）；
  - 亮色霜层=**纯白厚染 α150**（白霜压黑字，非 bg 灰染）；暗色
    独立调参=**画布深底染 α130**（旧值暗色形同虚设）；
  - 带宽：设置顶幕 120px（smoothstep→五次 smootherstep）；网格
    上/下沿 64/48px 换**前载三次曲线 (1-t)³/t³**——对称曲线在高
    峰值下于 50% 处读作「拦腰截断」，前载曲线让图标整行没入；
  - 网格沿峰值 230/235、染 150/140（标签文字整吞，无半遮半露）；
  - 滚动停稳 ~450ms 后重捕快照一次（`pump_veil_refresh`，单周期
  有界）——霜层反映停稳时的真实内容，消除「模糊的还是滚前内容」。
  - 评审流程：web 调研（Apple scrollEdgeAppearance=静止全透→滚动
    后恒定材质；ColorOS Aquamorphic=实时采样+柔和消融）→ Gemini
    3.1-Pro 出参数 → Opus 毒舌鉴定 → 迭代至双盖章。
- **虚化三修（同日晚，用户：纯渐变非调研结论、有断层）**：复用
  菜单玻璃管线（全窗快照 → blur → 纵向渐变蒙版贴图，glass.rs
  `build_veil_texture`）——设置页顶带凸形蒙版、网格上沿/下沿单向
  蒙版；快照身份/主题/条带为缓存键，命中零成本；之上叠 bg 轻染
  （暗 80/亮 70）保文字可读。快照缺失回退纯渐变。
