# 右键菜单毛玻璃：算法与配方（2026-09-10 毛玻璃化定稿；2026-09-12 暗色参数）

> 本文是 `duo/ui/qml/Main.qml` MenuGlassPlate 与 `Style.qml` 毛玻璃令牌
> 的唯一论述文档。代码里不重复这些内容。暗色令牌双值见 DESIGN.md §2；
> 玻璃开关契约见 §6。

## 1. 结构（三明治）

```
MenuGlassPlate（菜单大小）
├─ ① ShaderEffectSource 快照（过采样，1:1）
│     x/y = 快照原点 − 菜单原点（≈ −28）；尺寸 = sourceRect = 菜单 + 2×28
│     sourceItem = canvasRoot（bgLayer 画布 + 色斑 + StackView 页面）
│     live:false；open() 设 sourceRect + scheduleUpdate() 抓一帧
├─ ② MultiEffect（与 ① 同尺寸）
│     blur 0.75 / blurMax 32（二级 0.85；24px 档雾化背景文字）
│     saturation 0.45（二级 0.50，≈ ×1.45/×1.50，对齐胶囊矩阵档）
│     brightness 0.02（二级 0.04）——玻璃体始终比底板亮 ~10 级
│     contrast 0.06（二级 0.10）——浅底中高灰推向白饱和，拉开层阶
│     maskThresholdMin 0.5 + maskSpreadAtMin 0.4
│     maskSource = 过采样坐标系里与菜单同位的圆角白块（透明底）
└─ ③ 描边矩形（菜单大小，radius 12）
      GL：tint 0%（透明）+ 1px 黑 hairline 12%（二级 14%；内边框合成，
      纯白画布上 31 级暗刻）
      软件回退：不透明 menuFill #F7F7F9 + menuFillBorder 10% 黑
```

## 1.5 毛玻璃化（2026-09-10，flash 设计 × Opus 裁决）

用户裁决链：菜单 72% 白 → 与胶囊同步判"奶白"。Opus 终审：**三表面
家族统一 tint 0%**（胶囊/菜单/下巴），可辨性改由光学增益 + 描边承担；
elevation 阶梯从 tint 差改为 blur/sat/bright/contrast/描边五参数阶梯。
勘误存档：flash 对无彩画布上饱和增益的"色晕"效果过度承诺（#F5F5F7
色度 0.008，×1.45 后仍不可感——饱和增益只在彩色底景有价值）；
描边从 10% 上调 12%（纯白画布 25 级 → 31 级暗刻，防溶底余量）。
最坏复核：#FFFFFF 画布上玻璃输出 clamp 255、描边 224，跨边界 62 级
视觉事件；墨字 16.85:1 AAA。矩阵档与视频侧胶囊对齐见
window-experience.md §11 毛玻璃化。

## 2. 硬规则

1. **过采样 1:1**：快照层尺寸 == sourceRect 尺寸 == 模糊层 == 蒙版底板。
   玻璃内容与真实背景像素对位；贴窗边时快照原点内收、显示偏移同步
   补偿（`menuOffX = sx − px`），1:1 恒成立。
2. **28px 边距 > 模糊核触及半径**（0.75×32 = 24px）：菜单可见边缘的
   模糊核心永远采到真实内容，不碰纹理边界。
3. **maskThresholdMin 0.5 是裁切开关**：MultiEffect 默认阈值窗 0..1 =
   恒等映射，蒙版从不裁切（蒙版缺它 = 过采样模糊层整块方形透出，
   即"两层玻璃"）。
4. **maskSpreadAtMin 0.4 是亚像素坡**：smoothstep 阈值窗 [0.1, 0.9]；
   spread 是归一化 alpha 窗，硬 step 在 125%/150% DPR 下相位抖动出毛刺。
5. **autoPaddingEnabled 必须关**（真机 1.25× DPR 实测，2026-09-09）：
   默认 autoPadding 扩大 MultiEffect 绘制边界，蒙版纹理被拉伸到扩大后
   的边界 → 裁切落在比菜单大一圈、带偏移的圆角矩形上，菜单外溢出
   ~14k 像素 = "两层玻璃 + 外层圆角毛刺"；关掉后溢出归零。28px 过采样
   边距使 autoPadding 毫无必要（可见边缘的模糊核心采不到纹理边界）。
5. **坐标 Math.round**：菜单 x/y 取整，两层光栅化（纹理 vs 矢量）的
   半像素相位差断根。
6. **设备像素网格吸附**：分数 DPR（1.25/1.5）下，菜单位置/快照几何只有
   落在设备像素整数上（snapGrid：1.25→4px 格、1.5→2px 格）才能让快照与
   显示两级采样完全对齐；偏网格 1 逻辑像素会重采样出 ~0.5-1 设备像素的
   玻璃内容漂移（"有时候偏移"）。菜单打开期间快照 live 连续采样（首帧
   永不吃旧纹理），关闭即停。
7. **蒙版只做 alpha 裁切**（直角 bug 根治结构）：不要改回方形采样层。
7. **软件回退路径**（!Style.glassBlur，WSL/软件后端）：①②隐藏（不跑
   着色器即免采样），③换不透明 menuFill。

## 3. 配方依据（三轮外审）

- **Opus 审计（方案 A「Win11 Acrylic」，2026-09-09）**：快照源必须含
  画布（原 stack 只含半透明卡片，模糊对透明底凭空合成白雾 = "白光"
  元凶）；色斑需可感知（ΔE>1）玻璃才有折射内容。
- **gemini-3.8-flash 终审（2026-09-09）**：blur 提到等效 24px（15.6px
  打不碎背景文字，透出"脏灰斑"）；黑 hairline（25% 白在浅画布 ΔE<1 =
  无边框）；spread 0.4 亚像素坡；二级浮层 elevation 阶梯（零阴影铁律
  下的分层替代）。
- **毛玻璃化终审（2026-09-10，flash × Opus）**：三表面家族统一
  tint 0%（用户链：72% 白 → 与胶囊同步判"奶白"）；可辨性改由光学
  增益（brightness+contrast，玻璃体比底板亮 ~10 级）+ 描边 12% 黑
  （纯白画布 31 级暗刻，Opus 从 flash 的 10% 上调）承担；饱和增益
  只在彩色底景有价值（#F5F5F7 色度 0.008 不可感——勘误 flash 的
  "色晕"承诺）；elevation 阶梯改 blur/sat/bright/contrast/描边五参数。
- 色斑：同心三层 Rectangle 逼近径向衰减，核心 alpha 0x14–0x16
  （蓝左上 / 绿右下），tint 0% 后色斑直接透出，玻璃有彩可折。

## 4. 迭代史（真机反馈 → 根因）

| 轮 | 反馈 | 根因 | 修复 |
|---|---|---|---|
| 1 | 白光、死白、质感差 | 快照源 = stack（透明底） | 快照源换 canvasRoot + 配方 A |
| 2 | 背景会移动位置 | sourceRect 外扩 16px 塞进菜单大小显示项（缩放 ≈0.8 且贴边后漂移） | 过采样 1:1 |
| 3 | 两层玻璃 + 外层圆角毛刺 | maskThresholdMin 默认 0 = 蒙版从不裁切，过采样层整块透出 | threshold 0.5 + spread 0.4 + 黑 hairline |
| 4 | 仍有两层（threshold 后） | autoPadding 默认拉伸蒙版到扩大边界 → 裁切比菜单大一圈（真机 1.25× 实测溢出 14k px） | autoPaddingEnabled: false（实测溢出归零） |
| 5 | 偶发内容偏移 | 分数 DPR 下菜单位置偏设备像素网格 → 两级采样分数偏移 | snapGrid 网格吸附 + 打开期间 live 采样 |
| 6 | 整体观感"奶白"（与胶囊同步反馈） | 72%/82% 白 tint 把画布方差压进狭小浅色域 = 白皮 | tint 0% 毛玻璃化 + 光学增益 + 12% 黑描边（2026-09-10） |

## 5. 验收标准（真机）

1. 125%/150% DPI 凑近看四角：连续平滑，无台阶、跳点、毛刺。
2. 菜单盖住背景文字：字形彻底粉碎成灰雾，无笔画残影。
3. 纯白/纯空白画布呼出：凭描边 + 玻璃亮度差 0.1s 可辨，
   不溶不粘（tint 0% 后防溶底 = 描边 + brightness/contrast 双保险）；
   暗色画布同验（描边翻白，玻璃略亮于底板）。
4. 蓝绿色斑交界处：淡彩透过玻璃可感（tint 0% 后色斑直接透出），
   非死白非脏灰；暗色下色斑降 25% 后仍可感且不「嗡」。
5. 二级浮层：更亮更实的玻璃板（blur/sat/bright/contrast/描边五参
   阶梯），两级边界清晰，不透视穿透。
6. 玻璃内容与菜单外真实背景严丝合缝（色斑边缘连续），不同落点不漂移。

## 6. 玻璃材质总开关（2026-09-12）

`settings glass_enabled` 实装为「玻璃材质」总开关，三表面统一：

- **QML 菜单**：`Style.menuGlass = glassBlur（着色器能力）&&
  glassWanted（用户开关，ctrl.glassMaterial）`；任一为假走不透明
  menuFill 回退（与软件后端同路径，亮 #F7F7F9 / 暗 #2C2C2E）。
- **会话窗上巴/下巴**：argv `--glass 0|1`（controller `_pin_glass` 每次
  启动 fresh-read settings）；关 = C# 普通材质（见 window-experience.md
  §11 普通材质节）。
- 语义：关玻璃 ≠ 降级——是另一种正式材质，双主题都验收。
