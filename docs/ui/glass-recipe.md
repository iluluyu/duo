> egui 侧（duo-panel `glass.rs`）终态配方见 §8——**沉浸上巴 / 系统下巴的
> 移植基线 = §8.6**。代码里不重复本文内容；暗色令牌双值见 DESIGN.md §2；

## 1. 结构（三明治）（QML 侧）

```
MenuGlassPlate（菜单大小）
├─ ① ShaderEffectSource 快照（过采样，1:1）
│     x/y = 快照原点 − 菜单原点（≈ −28）；尺寸 = sourceRect = 菜单 + 2×28
│     sourceItem = canvasRoot（bgLayer 画布 + 色斑 + StackView 页面）
│     live:false；open() 设 sourceRect + scheduleUpdate() 抓一帧
├─ ② MultiEffect（与 ① 同尺寸）
│     blur 0.75 / blurMax 32（二级 0.85；24px 档雾化背景文字）
│     saturation 0.45（二级 0.50，≈ ×1.45/×1.50，对齐胶囊矩阵档）
│     brightness 0.02（二级 0.04）——玻璃体始终比底板亮 ~10 级
│     contrast 0.06（二级 0.10）——浅底中高灰推向白饱和，拉开层阶
│     maskThresholdMin 0.5 + maskSpreadAtMin 0.4
│     maskSource = 过采样坐标系里与菜单同位的圆角白块（透明底）
└─ ③ 描边矩形（菜单大小，radius 12）
      GL：tint 0%（透明）+ 1px 黑 hairline 12%（二级 14%）
      软件回退：不透明 menuFill #F7F7F9 + menuFillBorder 10% 黑
```

## 1.5 毛玻璃化（2026-09-10，flash × Opus 终审）

三表面家族（胶囊/菜单/下巴）统一 **tint 0%**——可辨性改由光学增益 +
描边承担（用户链：72% 白 tint 判「奶白」）。饱和增益只在彩色底景有价值
（无彩画布 ×1.45 不可感）；描边定 12% 黑（纯白画布 31 级暗刻防溶底）。
视频侧胶囊对齐见 window-experience.md §11。

## 2. 硬规则

1. **过采样 1:1**：快照层尺寸 == sourceRect 尺寸 == 模糊层 == 蒙版底板。
   贴窗边时快照原点内收、显示偏移同步补偿，1:1 恒成立。
2. **28px 边距 > 模糊核触及半径**（0.75×32 = 24px）：菜单可见边缘的
   模糊核心永远采到真实内容，不碰纹理边界。
3. **maskThresholdMin 0.5 是裁切开关**：默认阈值窗 0..1 = 恒等映射，
   蒙版从不裁切（缺它 = 过采样模糊层整块方形透出 =「两层玻璃」）。
4. **maskSpreadAtMin 0.4 是亚像素坡**：硬 step 在分数 DPR 下相位抖动出毛刺。
5. **autoPaddingEnabled 必须关**（真机 1.25× 实测）：默认 autoPadding 把
   蒙版拉伸到扩大边界 → 裁切比菜单大一圈，外溢 ~14k 像素「两层玻璃 +
   圆角毛刺」；关掉归零。28px 边距使 autoPadding 毫无必要。
5. **坐标 Math.round**：两层光栅化的半像素相位差断根。
6. **设备像素网格吸附**：分数 DPR（1.25/1.5）下菜单位置/快照几何必须落在
   设备像素整数（snapGrid），否则两级采样重采样出玻璃内容漂移。菜单打开
   期间快照 live 连续采样，关闭即停。
7. **蒙版只做 alpha 裁切**：不要改回方形采样层。
7. **软件回退路径**（!Style.glassBlur）：①②隐藏，③换不透明 menuFill。

## 3. 配方依据（三轮外审，2026-09-09/10）

- **Opus**：快照源必须含画布（只拍半透明卡片会对透明底凭空合成白雾 =
  「白光」元凶）；色斑需 ΔE>1 玻璃才有折射内容。
- **gemini-3.8-flash**：blur 提到等效 24px（15.6px 打不碎背景文字，透出
  脏灰斑）；spread 0.4 亚像素坡；黑 hairline；二级 elevation 五参阶梯。
- **毛玻璃化终审**：tint 0% + 光学增益 + 12% 黑描边；饱和增益只在彩色
  底景有价值（勘误 flash 的「色晕」承诺）。
- 色斑：同心三层 Rectangle 逼近径向衰减（蓝左上/绿右下），tint 0% 后
  直接透出，玻璃有彩可折。

## 4. 迭代史（QML 侧，真机反馈 → 根因）

| 轮 | 反馈 | 根因 | 修复 |
|---|---|---|---|
| 1 | 白光、死白、质感差 | 快照源 = stack（透明底） | 快照源换 canvasRoot |
| 2 | 背景会移动位置 | sourceRect 外扩塞进菜单大小显示项（缩放 ≈0.8 且漂移） | 过采样 1:1 |
| 3 | 两层玻璃 + 圆角毛刺 | maskThresholdMin 默认 0，蒙版从不裁切 | threshold 0.5 + spread 0.4 |
| 4 | 仍有两层 | autoPadding 拉伸蒙版到扩大边界（实测溢出 14k px） | autoPaddingEnabled: false |
| 5 | 偶发内容偏移 | 分数 DPR 下偏设备像素网格 | snapGrid 网格吸附 + live 采样 |
| 6 | 观感「奶白」 | 72%/82% 白 tint 压扁画布方差 | tint 0% + 光学增益 + 描边 |

## 5. 验收标准（真机）

1. 125%/150% DPI 四角连续平滑，无台阶、跳点、毛刺。
2. 菜单盖住背景文字：字形彻底粉碎成灰雾，无笔画残影。
3. 纯白/纯空白画布呼出：凭描边 + 玻璃亮度差 0.1s 可辨，不溶不粘；
   暗色画布同验（描边翻白，玻璃略亮于底板）。
4. 蓝绿色斑交界处：淡彩透过玻璃可感，非死白非脏灰。
5. 二级浮层：两级边界清晰，不透视穿透。
6. 玻璃内容与菜单外真实背景严丝合缝，不同落点不漂移。

## 6. 玻璃材质总开关（2026-09-12）

`settings glass_enabled` = 「玻璃材质」总开关，三表面统一：

- **QML 菜单**：`Style.menuGlass = glassBlur && glassWanted`；任一为假走
  不透明 menuFill 回退（亮 #F7F7F9 / 暗 #2C2C2E）。
- **会话窗上巴/下巴**：argv `--glass 0|1`（controller 每次 fresh-read）；
  关 = C# 普通材质（window-experience.md §11）。
- 语义：关玻璃 ≠ 降级——另一种正式材质，双主题都验收。

## 7. 文字保底光晕（QML 侧；2026-09-14 软光晕定稿）

tint 0% 玻璃把底景明度原样透上来：菜单飘到深色图标（亮主题）或白底图标
（暗主题）上时字形边界对比掉到 2.2–2.9:1。厂商对策（Apple luminosity、
微软 exclusion blend）是逐像素机制，Qt 侧拿不到——推导见
`docs/ui/RESEARCH-LEGIBILITY.md`。硬描边被否：`Text.Outline` 无论 alpha 多低
都把字形外扩半像素（覆盖率 +146%，Regular 读成 Medium）+ 硬边廉价感。

**实装**：`MenuLabel` = 双层文字——底层 `mlHalo`（同文字剪影，同向低
alpha，layer 模糊 ≈5.6px）+ 顶层清晰文字（普通光栅路径，字形零改动）。
额度：亮 38% 白 `#61FFFFFF` / 暗 50% 黑 `#80000000`。σ 只加宽缓冲、几乎
不抬边界对比，抬边界只能加 α（实测与「优先加 σ」建议相反）。底景同调时
不可见（画布可见度 1.00/1.05）；只在 `Style.menuGlass` 双闸门下跑（关玻璃
不建 FBO）。

| 方案 | 字形覆盖率 | 最坏落点边界 | 画布可见度 |
|---|---|---|---|
| 硬描边 85% / 40% | **+146%**（变粗） | 16.7 / 12.3:1（硬边廉价） | 1.00 |
| **软光晕 2.8px（实装）** | +0% | 10.2:1（亮）/ 13.2:1（暗） | 1.00 / 1.05 |
| 无保底 | +0% | 2.4–2.9:1（字丢） | — |

契约测试 `tests/test_menu_legibility.py` + `tests/test_qml_app.py`；选型可重跑
`docs/ui/probes/menu_halo_candidates.py`；出图在 `docs/validation/assets/`。

## 8. egui 实装与上巴/下巴移植基线（duo-panel，2026-09-18 定稿）

duo-panel 菜单毛玻璃 = **单帧快照 + CPU 模糊 + 贴图**管线（`glass.rs`），
一二级菜单参数完全一致。本节为终态配方；§8.6 是上巴/下巴移植基线。

### 8.1 管线

全窗设备像素快照（闲时常驻捕获，开菜单即切图零延迟）→ 菜单矩形外扩
56px 裁剪 → 3×box blur（σ8 高斯近似）→ 光学增益 → 高光软膝滚降 →
纵向光泽 sheen → 圆角 SDF 蒙版（r12 + 0.5px 羽化）→ 贴图垫在内容之下
（`Shape::Noop` 预占 ShapeIdx 底位 + `painter.set` 原地回填，首帧零空白）。

### 8.2 增益公式（gamma 空间逐像素）

| 阶段 | 公式 | 目的 |
|---|---|---|
| contrast | d=L−0.11；d>0 时 L+=d×0.04 | pivot 单侧扩张，暗底永不下拉 |
| brightness | L += 0.025 | 暗底 28→34 级微抬（略亮于底板） |
| saturation | c = luma + (c−luma)×1.65 | 彩度回注（模糊洗彩度，灰=雾） |
| soft knee | Hermite(a=0.35, b=0.45, 尾线 0.40+(L−0.40)×0.15) | 白底穿透 ≤128 级；值+斜率双连续 |
| sheen | c ×= 1 + 0.045×(1−2y/h) | 顶亮底暗，环境光真实感 |

亮色主题：σ8、brightness 0.02、contrast 0.06（pivot 0.5）、sat ×1.45、
无滚降、无 sheen。**软膝必须三次 Hermite**（值+斜率双连续，膝外输出与
硬拐点公式完全一致）——smoothstep 值混合在 R<L 区有非单调凹陷，禁用。

### 8.3 设计理念（Apple Liquid Glass × ColorOS 17，真机收敛）

- **σ8** = 「干净色彩晕染 + 可辨细节」平衡点：6.5 半糊残影=雾蒙蒙（否），
  11 过糊缺细节（否）。
- **饱和度回注**是玻璃「活着」的关键（Apple）；材质是设计过亮度带的
  结构保留面，不是压黑矩形——0.22/0.04 深压档把 56-255 级压进 ~9 级
  窄带 = 死灰板，真机否决。
- **可读性靠亮度带 × 墨色的构造性保证**：白底输出 127 级，恰在 ≤128
  （白字 ≈4:1）约束的帕累托边界（agy opus-4.6 终审；0.42/0.18→132 违约）。
  美感优先、可读性兜底。
- 顶部镜面棱线试装后真机判过重，已移除；纵向光泽 sheen 保留。

### 8.4 暗色候选单位矩阵（`DUO_GLASS_UNIT`，默认 Unit 3；全档 σ8 / pivot 0.11 / sheen 0.045）

| 单位 | bright/cont/sat | tint | ceiling/slope | 定位 |
|---|---|---|---|---|
| 0 | +0.025 / 0.04 / ×1.65 | — | — | 纯光学对照（无滚降） |
| 1 | +0.020 / 0.04 / ×1.65 | 4% #242428 | 0.42 / 0.12 | 暖晶（白底 ~127） |
| 2 | +0.025 / 0.04 / ×1.65 | — | 0.36 / 0.12 | 强防护（白底 ~114，AA） |
| **3 默认** | +0.025 / 0.04 / ×1.65 | — | 0.40 / 0.15 | 帕累托边界（白底 127，≈4:1） |
| 4 | +0.035 / 0.03 / ×1.60 | — | 0.44 / 0.10 | 极通透（白底 ~128 踩线） |

### 8.5 工程硬规则（egui/wgpu 真机教训）

1. 菜单矩形量化到设备像素网格（`snap_rect_device_px`）+ 1 逻辑 px 容差
   冻结（`rect_within_tol`），否则布局尾差触发逐帧重拍 = 持续晃动。
2. 半透明交互色必须 `from_rgba_premultiplied`（unmultiplied 在构造时经
   伽马反算，被 wgpu 线性预乘直灌后 hover 底飙到 110 级泛白）；静态层
   一律在 theme 预合成为不透明色。
3. 快照缺失不放弃菜单：跳画 + 请求重截 + `request_repaint`，下一帧无感填补。
4. 玻璃开 = `window_fill` TRANSPARENT + 无阴影 + 无 window_stroke，
   egui 原生灰底零残留，全由毛玻璃贴图呈现。
5. 宽度锁：`menu_width` 128 / margin 4 / 内容 120，全控件定宽防发散。
