# Duo 面板设计规范（rule 文档）

> 本文是所有 UI 改动的验收标准。任何新组件、新文字、新图标、新动效，先对照本文；
> 与本文冲突的实现视为 bug。修改本文需要用户拍板。
>
> 美学定位：**安静的玻璃与纸** —— Windows 11 云母/亚克里的材质秩序 × Apple HIG
> 的层级与克制。面板应当像"天生就在那里"，不争抢注意力。

## 0. 十条铁律

1. **默认删除**。删任何东西之前先问"删了会不会更对"；答案是肯定的就删。
   组件、文字、图标、分隔线一律适用。
2. **文字只为状态与操作存在**。装饰性文字、重复说明、可以由视觉自解释的
   标签，一律不加。一句能说完的不用两句。
3. **图标克制**。每加一个图标都要过"是否语义必需"——纯文字已经清楚的不加
   图标，图标不能自解释的不如不加。同一画面图标风格必须统一（线宽、圆角、
   底材）。
4. **一个画面最多一个强调色元素**。#007AFF 是唯一强调色，只给主操作/选中态。
5. **同心圆角**。嵌套圆角遵循 内半径 = 外半径 − 内边距；卡 16 / 控件 10 /
   浮层 12 / 图标按 60px 的 23% ≈ 14；胶囊类（搜索框、芯片、Toast、
   状态钮）= 高度/2。取值来源是 G2 连续曲率的视觉比例，实现允许圆弧
   近似，大表面可用 squircle path。
6. **间距只用 4 的倍数**：8 / 12 / 16 / 20。页面左右留白 20。
7. **动效只允许 140ms 的透明度与颜色过渡**。禁止位移、缩放、弹跳、旋转、
   常驻动画。状态变化即动效时机，无状态变化不动。
8. **全界面零阴影**（2026-09-08 定稿）：QML 里矩形模拟的阴影在 GL
   下像贴上去的深色矩形，真机观感差——内容卡与浮层（菜单/胶囊/Toast）
   一律零阴影。分层只靠材质对比（cardFill 72% / flyoutFill 60% vs
   画布）+ 亮边。HTML 方案稿中的 CSS 模糊阴影仅示意相对深度，不实现。
9. **新组件必须归入四层之一**（见 §1），不引入第五层。
10. **改动必须出图对比**（`python scripts/qml_shots.py`，offscreen 渲染），
    主观视觉拿不准交视觉顾问（agy Opus）裁决，不再口头争论。

## 1. 材质四层

| 层 | 材质 | 用途 | 实现 |
|---|---|---|---|
| 画布 | 云母 | 窗口底 | 近不透明中性底（亮 #F5F5F7 / 暗 #1C1C1E）+ 极淡品牌色斑（现有），不随内容滚动 |
| 卡片 | 轻玻璃 | 设备卡、设置组、固定/镜像/运行卡 | 亮 rgba(255,255,255,0.72) / 暗 rgba(255,255,255,0.10)（合成 #323234，抬升面亮于画布）+ 1px 亮边（**零阴影**） |
| 浮层 | 亚克力 | 右键菜单、二级菜单 | **rgba(255,255,255,0.88 语义：tint 0% 毛玻璃）** + 亮边（零阴影；软件回退/关玻璃 = 不透明 menuFill：亮 #F7F7F9 / 暗 #2C2C2E） |
| 胶囊浮层 | 轻 | 顶栏胶囊、Toast、搜索聚焦 | rgba(255,255,255,0.60) / 暗白 7%（零阴影） |
| 内容 | 实体 | 图标、文字 | 不透明，直接置于上层材质之上 |

- **卡片不做背景采样模糊**（2026-09-08 定稿）：采样层是方形容器，GL
  后端下会在圆角卡上盖出直角补丁（Windows 真机复现）；而背景只有
  3-6% 透明度的色斑，模糊收益≈0。玻璃感 = 半透明填充 + 亮边 + 阴影。
  `Style.glassBlur` 令牌保留为未来真 DWM 亚克力（Mica/Acrylic backdrop）
  的开关。
- **暗色模式**（2026-09-12，glm-5.3-flash × gemini/sonnet 交叉设计、zai
  视觉验收两轮定稿）：材质语言不变，只换数值。暗色海拔阶梯 = 画布
  #1C1C1E < 菜单/胶囊 #2C2C2E < 卡 #323234 < 选中段 #48484A；黑透卡
  （卡片暗于画布）方案被 zai 验收否决（“发闷”，层级拉不开）。主题三态
  light|dark|system（Qt colorScheme 实时跟随，保存后即时切换）。

菜单毛玻璃（GL 路径）暗色参数：tint 0% 不变；blur 0.75/0.85 不变；
saturation 0.45/0.50 不变；brightness 暗 +0.05/+0.07（亮 +0.02/+0.04，
暗底玻璃略亮于底板——暗色海拔语义）；contrast 暗 +0.08/+0.10（亮
+0.06/+0.10，补偿暗底内容对比）；描边翻白：一级 14% / 二级 18%
（亮色 12%/14% 黑）。软件回退描边暗色白 10%。

字号阶梯：22（窗口标题）/ 15（主文字）/ 13（控件）/ 12（辅助）。不引入
新字号与字重（DemiBold 仅标题/选中态/图标首字）。

## 3. 组件规范

层级顺序：标题行 → 设备卡 → 固定应用卡 → 搜索 → 应用网格（裸排）→
芯片区 → Toast。状态区（卡）在上，查找区（搜索+网格）在下。

### 3.1 应用图标（60px，网格内）
- **真实图标优先（设备端系统渲染）**：控制器把 88+ 个包名推给
  `duo/resources/duo_icons.dex`（app_process，同 scrcpy server 部署形态），
  由设备 PackageManager 自己渲染启动器图标（adaptive 图层/inset/渐变/
  混淆资源全部原生处理，getDrawableForDensity 取高密度变体，legacy
  上限 576px），PC 侧只做裁切 432→288、白底重涂、G2 蒙版（缓存
  `.r11.png`，113 个图标 ~30 秒完成；APK 拉取 + aapt2 路径降级为无
  DEX 环境的 fallback）。后处理细节见 docs/ui/RESEARCH-ICONS.md §9。
- **预设图标**：已知常用应用（目录 27 个）用参数化 SVG 模板——品牌色
  微渐变底（顶部略亮）+ 白色原创字形（中文首字或字母，DemiBold）。
  **无内亮边、无外描边**（Qt SVG 下读成黑线，已删）。**不复制官方
  logo**，统一为"品牌色单字"体系，整套一致。
- **未知应用 fallback**：同上模板，底色由包名哈希从 12 色柔和色板取，字为
  标签首字。色板需能托住白字（相对亮度 ≤ 0.42）：
  #5F7292 #6F8468 #96725D #7D6B94 #628C87 #946363 #6C7FA3 #829462 #936280
  #628192 #8C7163 #746A92。深色底（如 #1C1C1E）的内亮边降为
  rgba(255,255,255,0.18)。禁止灰底圆（现状）——灰底圆只用于"加载中"一瞬。
  fallback 底板也是 G2 超椭圆角（JS 拼 SVG data-URI 渲染，与蒙版同构）。
- **所有图标统一 Apple 式超椭圆（|x/a|⁵+|y/b|⁵=1，r=50% 无直边）**：圆弧
  圆角在直边交点处曲率突变（60px 下有"切角感"），G2 连续曲率消除该
  拐点。三面同构：apps.py `g2_outline` 生成蒙版多边形（4x 超采样
  LANCZOS 回缩）；预设 SVG 模板同函数出 path；QML fallback 同公式
  JS 复刻。**白底忠实**（2026-09-13 用户复审定调）：白底是品牌资产
  （夸克/优酷/日历在官方白底上最显著），不再 tint 重涂——只垫平
  透明角；渐变底（高德）整体直通；全白无内容才涂冷银板
  (217,221,227) 兜底。透明底悬浮造型仍生成式处理：暗造型
  （计算器 luma<0.45）用边缘环色原色扩板，其余走 blob 同色板。
  adaptive 满宽前景（优酷整幅圆）不再缩放。

### 3.2 顶栏（通栏胶囊）

- **通栏**：整行覆盖页面横向（左右让出页面留白 20），高 32、圆角 16，
  亚克力；顶距 16（标题栏安全距离）。
- 段落「首页」「设置」**各占通栏一半**、文字居中（视觉平整），无图标：
  选中段 = 不透明纯白填充 + 圆角 14（上下留 2px）+ 主文字（与胶囊底
  60% 白强色差；微投影已删，72% 白色差太弱看不清在哪页）
  0 1px 3px rgba(0,0,0,0.06)；未选中 = 透明 + 次色 + hover 洗色 +
  手型光标。点击切换（设置 = push 设置页，首页 = pop）；两页常驻。
- 页面不再有大标题行与齿轮按钮；设置页顶部同样只有通栏胶囊（"设置"
  段亮起），无标题行、无返回按钮。
- Ctrl+, 与 Esc 快捷键保留。

### 3.3 AppTile（92×102 格）

- 图标 60px + 标签 12px（6 字截断）居中。未安装：整体 40% 透明度、禁点。
- hover：**图标区**极淡洗色（hoverWash，不洗整格），**无位移无缩放**。
- 磁贴**无置顶角标**（2026-09-13 用户复审：圆圈+星角标没有必要，已
  移除）：置顶状态由固定栏显示，置顶入口=右键菜单。
- 点击启动；已在运行 → 直达该会话虚拟屏（现有路由）。
- 固定=快捷方式（2026-09-13 用户复审定调）：网格**保留**已置顶应用，
  固定栏只是额外快捷入口。

### 3.4 固定应用卡（置顶）

- 设备卡下方、搜索框**上方**，仅当有置顶应用时出现：与设置页同语言
  的玻璃卡（cardFill + blur + 亮边，圆角 16，内边距 12），卡内 44px
  图标横排（Flow 换行），无标题、无说明文字、无按钮。与网格共用右键
  菜单与点击语义。
- 网格中不再出现置顶应用（置顶 = 移入固定卡；离开 = 回拼音序）。
- 宽窗口下卡片全宽、图标左起流动；窄窗口同样换行。

### 3.5 镜像卡

- 固定应用卡与搜索之间：同语言玻璃卡，高 64、内边距 12。
- 内容：左「设备镜像」15px DemiBold（+ 12px ink2 副行「整机投屏到窗口」？
  否——**无副行**，克制）；右「投屏」强调按钮 68×32 圆角 16。
- 无设备或引擎锁定时按钮禁用（40% 透明度）；设备卡不再带投屏按钮
  （纯状态展示：绿点 + 在线/离线 + serial）。
- **右键卡片**弹上下文菜单（与磁贴菜单同浮层语言）：
  `打开投屏` / hairline / **窗口栏**（2026-09-09 用户反馈“不够完整”
  后补全）：设备镜像无应用包，这里直接写设置页默认
  （`setDefaultBarMode` → settings.json `top/bottom_bar_mode`，与
  设置页同一对字段）——上巴 沉浸/系统、下巴 沉浸/系统/不显示
  （选项集与设置页对齐，选中圆点 = 当前默认；选毕关菜单，生效于
  下一次投屏）/ hairline / `镜像时关闭设备屏幕`（勾选态写回设置，
  即 Settings.turn_screen_off）。
- 媒体音量条：滑杆左侧 14×14 单色扬声器图标（Canvas 矢量，2026-09-09
  用户反馈“光秃滑杆看起来像画质调节”），设备离线时与滑杆一同隐藏。
- 运行中的镜像会话仍出现在底部运行卡（「设备镜像」芯片），不在此卡内。

### 3.6 搜索

- 固定卡之下、网格之上，高 36 的胶囊卡（圆角 18，与卡片语言合流：
  cardFill + blur + 亮边）：placeholder「搜索」（仅此一词），左侧放大镜
  细线图标，右侧清空按钮（有文字时才出现）。
- 即时过滤：标签原文包含 / 拼音首字母匹配（输入 `wx` 命中「微信」）。
  无结果时网格区显示一行辅助文字，无空态插画。
- 聚焦时亚克力浮层感；Esc 清空并失焦。Ctrl+F 聚焦。

### 3.7 右键上下文菜单

- 磁贴/固定卡小图标右键或长按弹出（长按吞 clicked 的机制保留）。
- 亚克力浮层，圆角 12，条目高 32、左右 12，分隔线 hairline，条目无图标
  （比例示意除外）。
- 条目：`打开` / `置顶到固定卡`｜`取消置顶` / 分隔 / **显示模式**区：
  - `自适应窗口`（当前默认，选中=左侧 4px 强调色圆点）：flex 虚拟屏
    跟随窗口尺寸；
  - `固定比例 ▸` **二级菜单**：横屏（21:9/16:9/4:3/1:1/机身）/ 竖屏
    （3:4/2:3/5:7/9:16/机身）两段小节头，每项 = 比例名（左）+ 比例
    圆角矩形示意（右，1.5px 描边按比例缩放）；选中项左侧 4px 强调
    色圆点。
  - **按应用记忆**（gui_prefs.json `display` 节）：选比例 = 该应用此后
    默认以固定分辨率常驻启动（窗口缩放只等比缩放画面）；选自适应 =
    回到跟随窗口。普通点击即按记忆的模式启动。
- 冻结比例集：横屏 21:9→3360×1440、16:9→2560×1440、4:3→1920×1440、
  1:1→1440×1440；竖屏 3:4→1440×1920、2:3→1440×2160、5:7→1440×2016、
  9:16→1440×2560；另各一组「机身」= 设备面板比例派生（wm size，真机
  待测）。选中比例即以固定模式建虚拟屏（CLI --width/--height）。
- 菜单度量：条目高 28、小节头高 20、内边距 4、条目圆角 8（同心：
  12−4）；比例示意横屏最大边=宽 16、竖屏最大边=高 14（拉开 1:1 与竖屏
  组的区分）；小节头与条目左对齐（12）。
- 点外部/Esc/选择后 140ms 淡出。

### 3.8 运行卡（底部）

- 仅当有会话时出现：与固定卡同语言的玻璃卡，卡内芯片横排（Flow 换行）。
- 芯片：绿点（8px，与设备卡同尺寸）+ 标签（点击 = 拉回该会话虚拟屏），
  **无横竖屏字样**，hover 时露出 ✕（opacity 0→1 140ms；未 hover 隐藏；
  ✕ hover 用极淡危险色洗底 rgba(255,59,48,0.08) + 危险色线条）。
- 运行卡底距两窗统一 56（为 Toast 让位）；网格底部 fade 不得叠上运行卡。

### 3.10 设置页

- 分组卡片：引擎（scrcpy/adb 路径 + FPS + 码率）/ 投屏质量（编码、音频、
  息屏、DPI、渲染倍率）/ 窗口栏（默认）/ 外观（主题三选一 + 玻璃材质
  开关）。**无标题行/返回按钮**（顶栏胶囊即导航，设置段亮起）；卡间距
  12；控件圆角统一 10；页面左右留白 20 与主面板一致。
- 音频选项行带行标签「音频」，选项名：**仅最新会话 / 全部会话 / 静音**
  （禁止裸写「最新」这类无上下文词）。
- 编码/音频分段控件**不配说明文字**（选项名已自说明）；息屏开关保留
  一条后果说明。
- 路径「检测」结果为**瞬时提示**：内联短标签波起，2.5s 后淡出，不留
  常驻绿/红文字（探测失败同理；保存失败仍走红条）。
- **文案 KISS（2026-09-12 Opus 裁决）**：说明文字一句能说完的不用两句，
  控件名自解释的不配说明（主题、玻璃材质均无说明）；窗口栏三个选项的
  术语解释入 hover tooltip（沉浸 = 无边框悬浮控件 / 系统 = 保留系统
  原生栏 / 不显示 = 不建栏），组内只留一行「应用未单独设置时生效」。
- **外观卡（2026-09-12）**：主题 = 亮色/暗色/跟随系统（保存后即时生效，
  system 经 Qt colorScheme 实时跟随系统切换）；玻璃材质 = 会话窗上巴/
  下巴与右键菜单的毛玻璃总开关（关 = 普通不透明材质，上巴/下巴随
  面板主题，生效于新会话与菜单下次打开）。
- 底部仅一个「保存」主按钮：‹ 返回即放弃（取消按钮冗余）。
- **删除**：DPI 数字框（flex 会话自动取设备密度，面板路径不再用手动 DPI；
  CLI `--dpi` 仍可用）、圆角三选一 + 滑块 + Canvas 预览（会话窗口圆角回归
  系统默认，G2 实验入口撤出设置，settings.json 手改仍生效）。
- 后端兼容：被删字段（dpi / corner_mode / corner_size_dip）在页面内隐形
  透传（load 读入 → collect 原样带回），因 SettingsApi.save 按整表构造，
  丢键即重置。

## 4. 性能预算

- 无常驻动画、无动画循环（Toast 计时淡出除外——它是状态）。
- 背景模糊采样 `live:false`；一帧内模糊层数 ≤2（卡片区共用一个采样源）。
- 图标：预设 SVG 按 60px 一次性渲染缓存；真实 PNG 异步解码。
- 搜索过滤在 UI 线程做纯内存匹配（≤200 应用无压力），不发任何 IO。
- 网格重建（QVariantList 模型限制）每批信息最多一次 emit（现有契约）。
- 不用 MultiEffect 阴影叠加半透明源（已知二次绘制问题）。

## 5. 自适应布局（硬性）

窗口是自由拖改的：**任何宽高比都必须好用，不为单一展示尺寸设计**。

- 网格列数随宽度自适应：`cellWidth = width / max(2, floor(width / 92))`，
  格子节奏（92×102）不变，列数变。
- 固定栏：窄窗口单行可溢出滚动/换行，宽窗口铺开单行；图标尺寸不变。
- 搜索框占满可用行宽；设备卡、芯片区（Flow 换行）天然自适应。
- 设置页单列卡片流，任何宽度下只变卡片内边距节奏，不变结构。
- 验收标准：出图至少盖窄版（420×660）与宽版（720×480）两档。
