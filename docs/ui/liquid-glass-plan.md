# 液态玻璃实现方案（八期，Apple×ColorOS17×自家菜单三源汇总）

> 输入：docs/ui/liquid-glass-apple-research.md、docs/ui/coloros17-research.md、
> 自家右键菜单生产配方（glass.rs main_params，用户认可）。
> 本文档 = 实现规格草案，关键分歧点由 Opus（agy）终裁定味。

## 1. 三源共识（直接落地，无需裁定）

1. **富模糊全材质**（菜单配方）：σ = 控件高度 25-50%（搜索 36px→σ8-10
   设备 px；胶囊 32px→σ7-8），**峰值 α255**——内容透过模糊显色，而非
   「半透染罩在模糊上」（当前 σ4+峰值 200 的薄洗法=发灰廉价感根源，
   Apple 调研 §3.2 明确点名）。
2. **增益复用 main_params**：saturation ×1.65（暗）/1.45（亮）、
   contrast 0.04-0.06、软膝天花/地板、sheen 0.045/0.02——菜单生产
   验证过的光学配方，杜绝单色奶白 tint。
3. **细背板**：岛合成背板 3px/格 → **1px/格**（设备像素级，~390×36
   cell），支撑折射不马赛克；滚动量化 3px 触发重建（成本：一次
   390×36 box blur ≈ 微秒级，可承受）。
4. **聚焦态保玻璃 + 实体化**（两家语义一致）：底板有效不透明 70%→
   88-92%（玻璃仍在，加实心提层）、模糊加重、rim 激活为高亮环
   （α~0.65）、**背景协同暗化 25-35%**（ColorOS 配方 5）。废除当前
   「聚焦=换实心色块」的材质断灭。
5. **定向 rim**（Apple 调研失败清单 #2 + ColorOS 配方 2）：废除均质
   1px 描边，改贴图内逐像素：顶部 α0.5-0.65 → 底部 α0.10-0.15 纵向
   衰减，1px 亮核 + 2px 亚像素软坡。
6. **内阴影厚度**：rim 内侧 0.5-1.5px 微暗带（Apple §3.2 #5）。

## 2. 实现机制（glass.rs 新 builder）

```
build_liquid_texture(fine_syn_backdrop):
  1. σ8 box×3 blur（细背板，设备像素级）
  2. 边缘折射带（Apple 法则 #1）：边缘 10-12% 短边宽度内，
     沿 SDF 梯度反向偏移采样（k=0.035×尺寸），R/B 微色散 ±1.5-2%
  3. apply_gains(main_params(dark)) —— 菜单光学
  4. ColorOS 混色：背板均值色 12% 回注（替代固定灰 tint）
  5. 定向 rim + 内阴影 + sheen → SDF 满圆角蒙版 α255
```

## 3. 分歧点 → 交 Opus 裁定

| # | 问题 | 选项 A | 选项 B | 倾向 |
|---|---|---|---|---|
| Q1 | 满材质 α255（菜单式）还是保留一点透（峰值 ~235）？ | 菜单式满材质（透感全靠模糊显色） | 半透峰值 235（直透+模糊双重） | A（两家+菜单共识） |
| Q2 | 浮岛软投影（ColorOS 配方 4：α~0.10、blur 12px）要不要？ | 加（空间分离感强，ColorOS 浮岛精髓） | 不加（项目历来无影设计，靠 rim 分离） | Opus 定 |
| Q3 | 折射强度 | k=0.035 标准值 | 保守 k=0.02（防 CPU 细背板折射出马赛克/噪感） | B（背板是合成的非真实截图，抗马赛克余量小） |
| Q4 | 聚焦态形态 | ColorOS 式：底板实体化+背景暗化 28%+rim 高亮 | Apple 式：几何外展（搜索条加宽）+抬升 | A（窗口固定宽，外展无空间；暗化零成本） |
| Q5 | 圆角 | 现行圆 r=SDF | ColorOS 超椭圆 n≈3.5 squircle | 圆 r（SDF 现成，squircle 公式换入成本低，留后续） |

## 4. 组件映射

- **搜索栏**：Q1 材质 + 折射 + 定向 rim；聚焦=Q4；清空钮/放大镜浮于
  玻璃体。
- **分段胶囊岛**：同材质 σ7；拇指=玻璃上的实体滑块（已调对比）。
- **右键菜单**：不动（生产配方已获用户认可）。
